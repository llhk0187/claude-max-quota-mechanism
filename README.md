## Claude Max额度是怎么算的：5 小时窗口 + 每周上限

先纠正一个常见误解：Max 的额度不按“条数”算。官方按用量计量，同样一份额度，短问答能聊几百条，开深度思考啃长文档可能几十条就见底。所以网上流传的“Max 能发多少条消息”都只是参考值，不是承诺。

真正的额度结构是两层：一个 5 小时的会话窗口，加一个每周上限。

### 5 小时会话窗口

用量按“过去 5 小时”滚动累计，旧的消耗会随时间移出窗口，容量跟着释放。所以撞限不会把你锁一整天——停一阵子就能继续。一天可以安排多轮高强度会话，只要间隔开就行。

### 每周上限

这才是更硬的天花板。官方帮助文档明确 Max 套餐有覆盖所有模型的每周限额，多篇第三方资料还提到 Sonnet 系列另有单独的每周上限。每周限额在固定时间重置，这个时间绑定在你的账号上，不随你什么时候开始用、什么时候订阅而变，每个周期都给满额。下一次重置时间在 Settings > Usage 里能直接看到。

### 什么最烧额度

几类消耗大户，按夸张程度排：

- **深度思考**：单次回复的消耗可以达到普通回复的 10 倍以上
- **Claude Code 的代理式会话**：每次读文件、跑工具、执行测试都要过一遍模型，普通聊天永远到不了这个消耗速度
- **长上下文和大附件**
- **Fable 5 和 Fable 5.1**：在 Max 套餐里可以把每周限额的至多 50% 花在这两个模型上、不额外收费，但它们比其他模型烧限额更快（Pro 上这两个模型从第一个 token 起就走 usage credits）
- **Cowork 的多步任务**：和 Claude Code 共用同一个额度池，上午跑了一轮重度自动化，下午写代码的余量就会缩水

## 5x 和 20x 的额度差距有多大

官方给出的规划参考是：短对话、低强度模型的前提下，Max 5x 每 5 小时窗口大约 225 条短消息，Max 20x 大约 900 条。作为对比，有第三方测算 Pro 在复杂任务上大约 40-45 条就到顶。换成重任务这些数字会明显缩水，但倍率关系不变。

顺手算一笔单位成本的账：Max 20x 是 200 美元买 20 倍用量，折算下来每个“1x 单位”10 美元，只有 Pro 的一半；Max 5x 是 100 美元买 5 倍，单位成本和 Pro 持平。换句话说，5x 买的主要是“不中断”和优先体验权，20x 才在单价上真的占了便宜。

还有个容易被忽略的细节：Cowork 的每日任务批量数也随档位变化。Pro 大约 15-20 批，Max 5x 约 30 批，Max 20x 实际使用中基本不设限。如果你打算把多步办公任务交给后台跑，这个差异比聊天条数更实在。

## 为什么开了 Max 还是会撞限

原因不复杂：5 小时窗口之上还有每周上限，而后者不会滚动回血。窗口被撞了停一会儿就好，每周额度烧完就只能等固定重置时间。

最容易撞限的场景是 Claude Code 长时间跑代理任务，这也是“我都开 Max 了怎么还撞限”这类抱怨的主要来源。好在这块在 2026 年 5 月有过一次实质改善：Anthropic 把 Claude Code 的 5 小时限额在 Pro、Max、Team、Enterprise 各档翻倍，同时取消了 Pro 和 Max 用户的高峰期限流。同样的 5x、20x 倍率，现在能跑的量比这个套餐刚上线时大得多。

用量节奏也影响体感。如果你是“某几天猛冲、其他时间闲置”的类型，滚动窗口对你有利，闲置日的容量不会浪费；如果一周七天连续高强度，那每周上限就是你会反复碰到的那堵墙，这种用法才真正需要 20x。

1. **等重置**。5 小时窗口持续回血，每周限额在账号绑定的固定时间刷新，Settings > Usage 能看到倒计时。

4. **用限额重置道具**。如果账号里有限额重置（limit reset），可以直接把 5 小时或每周额度拉满。

## Claude Max 额度常见问题

**Max 的额度是无限的吗？**
不是。5x 和 20x 是相对 Pro 的倍率，5 小时窗口和每周上限照样存在，官方也保留了按需施加额外限制的权利。

**Max 套餐包含 API 吗？**
按官方帮助中心目前的说明，Max 和 Team 套餐包含每月的 Claude API 额度，具体数量以官方页面为准。这不等于订阅费变成 API 余额——交互使用走订阅，自己代码里的程序化调用主要还是通过 Console 按 token 计费。

**额度什么时候重置？**
会话窗口每 5 小时滚动刷新；每周上限在绑定账号的固定时间重置，不随订阅起始时间变化。Settings > Usage 可以查看。

**Max 有年付或者折扣吗？**
没有。Max 只提供月付，官方也不设常规折扣，只有不定期通过官方渠道发布的限时活动。

**每周额度提前用完怎么办？**
等固定重置时间、开 usage credits 按 API 费率继续用，或者升级到更高档位。

**在手机上订阅价格会不一样吗？**
可能。网页端是 100 和 200 美元，移动端价格取决于应用商店平台，下单前看清楚。
